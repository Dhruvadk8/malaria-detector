Getting Started

Welcome to MalariaScope Pro! This guide will help you understand how to use our AI-powered malaria detection system effectively.

System Requirements

  • Modern web browser (Chrome, Firefox, Safari)
  • Internet connection
  • Digital microscope or scanner for blood smear images

Uploading Images

Image Requirements
  • Supported formats: PNG, JPG, JPEG, TIFF
  • Maximum file size: 5MB
  • Recommended resolution: 1024x1024 pixels or higher
  • Clear, well-focused blood smear images

Upload Methods

  1. Drag and drop files directly onto the upload area
  2. Click the upload area to browse your files
  3. Use the "New Analysis" button from any page

Interpreting Results

Parasitized

Indicates the presence of malaria parasites in the blood sample.

  • Red warning indicator
  • Confidence score above 50%
  • Requires immediate attention
Uninfected

No malaria parasites detected in the blood sample.

  • Green success indicator
  • Confidence score above 50%
  • Regular monitoring recommended

Managing History

Keep track of all your analyses and monitor trends over time:

  • View complete analysis history
  • Filter and sort results

  • Track detection trends and patterns

Best Practices

Tips for Best Results
  • Use high-quality microscope images
  • Ensure proper lighting and focus
  • Clean and properly stained slides
  • Regular system calibration
  • Keep records of all analyses

Troubleshooting

  • Check file format and size
  • Ensure stable internet connection
  • Clear browser cache
  • Try a different browser

  • Verify image quality
  • Check for proper staining
  • Ensure correct focus
  • Try reprocessing the image
